# Setting up fastapi server (Mac/Linux) 
- Setup a virtual environment           | `python -m venv .venv`
- Enter virtual environment             | `source ./.venv/bin/activate`
- Installing Fastapi and uvicorn        | `pip install fastapi uvicorn`
- Update depency requirement.txt list   | `pip freeze > requirements.txt`
- Running Fastapi Server                | `python main.py`
- Accessing API documentation           | `localhost:3008/docs`
