## ADR-001 
- Status: In Review
- Date: TBD
- Decision: All backend logic runs in Rust as Tauri commands, no seperate Python or Nodejs server, and no separately installed LLM runtime: llama.cpp runs in-process, so users install nothing but Stacknote.

### Context
- Stacknote is a cross platform desktop app meant to be distributed as a single installer, built on Tauri V2 with React + Typescript + Tailwindcss frontend.
- Original plan was to use a Python (FastAPI) backend for Rag pipeline.
- Running Python inside Tauri requires a bundled side car (PyInstaller or Nuitka), adding packaging weight per platform, resulting in potential slower startups and more work per Operating System builds and process lifecycle work.
- Every v1 component has a maintained Rust option
- notify (File watching)
- fastembed-rs (Embeddings)
- lancedb (Vector DB)
- llama-cpp-2 (in-process llama.cpp inference)
- pdf-extract/pdfium-render (PDF manipulation and Extraction)
- rusqlite (metadata)
- Project must stay FOSS (Free and Open Source Software)
- Target users can't be expected to install Ollama or use a terminal.

## Decisions
| Layer           | Choice                                                                                                   |
|-----------------|----------------------------------------------------------------------------------------------------------|
| Shell           | Tauri v2                                                                                                 |
| Frontend        | React + TypeScript + Tailwind CSS                                                                        |
| Backend         | Rust, exposed to the UI as Tauri commands (no HTTP server)                                               |
| LLM runtime     | llama.cpp in-process via llama-cpp-2; Metal on macOS, Vulkan on Windows and Linux, CPU fallback          |
| LLM models      | GGUF, downloaded on first run; tier picked from detected RAM (Lite ~1 GB, Standard ~2 GB, Quality ~4.5 GB); resumable, checksum-verified |
| LLM abstraction | LlmBackend trait; an optional Ollama backend for power users can be added later                          |
| Embeddings      | bge-small via fastembed-rs, in-process                                                                   |
| Vector store    | LanceDB (lancedb Rust crate), embedded                                                                   |
| Metadata        | SQLite (rusqlite): file paths, content hashes, chunk mapping                                             |
| File watching   | notify crate                                                                                             |
| PDF parsing     | pdf-extract; pdfium-render for difficult PDFs                                                            |
| OCR             | Deferred to v2 (Tesseract via leptess, or OS-native OCR)                                                 |
| License         | Open source (license to be chosen: MIT or Apache-2.0 vs GPL-3.0)                                         |

## Alternate Considerations

| Option                                       | Pros                                                              |
|----------------------------------------------|-------------------------------------------------------------------|
| Python FastAPI sidecar                       | Richest RAG/ML ecosystem; faster if already fluent in Python      |
| Hybrid (Rust core + Python for parsing/OCR)  | Keeps Python's document libraries                                 |
| Electron + Node or Python                    | Mature tooling, familiar web stack                                |
| Require user-installed Ollama                | No inference code to maintain                                     |
| Bundle Ollama as a sidecar                   | Familiar model management                                         |
| Rust in-process with embedded llama.cpp      | One binary, nothing else to install, fast startup, no IPC server  |

### Consequences

#### Positive
- Single smaller installer per OS, no Python runtime to bundle or manage
- One build pipeline (Tauri + Cargo) in CI for macOS,Win, Linux
- Lower resource consumption, memory usage and faster startup

#### Negative
- Rust learning curve
- Complex document parsing
- Cross-platform GPU builds (Metal, Vulkan, CPU fallback) make CI the hardest part of the project; models of 1–4.5 GB download on first run.
